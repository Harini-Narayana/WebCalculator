# Web Calculator

A simple and visually appealing web calculator designed to perform basic arithmetic operations through a clean and interactive interface. The project focuses on responsive design, structured layouts, and smooth user experience.

Built using HTML and CSS, the calculator highlights frontend design principles while maintaining a modern and user-friendly appearance.

## Features
- Basic calculator layout
- Clean and responsive interface
- Interactive button styling
- Well-structured design
- Lightweight and easy to use

## Tech Stack
- HTML5
- CSS3

## Purpose
This project was created to improve frontend development skills by designing a calculator interface with a focus on layout, styling, and user experience.

## Future Improvements
- Add JavaScript functionality
- Include scientific calculator features
- Add dark/light mode
- Improve responsiveness across devices
